# Legacy website archive

Archived: 25 August 2026 (Europe/Athens)

This directory preserves the pre-`public/` ASK FOR TASK static site and its
uncommitted root-homepage hardening work. It is historical evidence, not a
deployment source.

The live Cloudflare asset source is `public/`, as configured in
`wrangler.jsonc`. New website changes must be made only in `public/` unless a
future migration explicitly changes that configuration.

Nothing in this archive should be linked from deployed HTML, included in the
sitemap, or used as a fallback visual system. Files may be restored by moving
them back to their original repository-root paths if historical recovery is
ever required.
